01

Add once, install anything

claude-code
# register the marketplace
/plugin marketplace add contract-hero/plugin-marketplace

# install whatever you need
/plugin install sui-pilot@contract-hero
/plugin install code-forge@contract-hero
/plugin install agentic-community-college@contract-hero

Restart Claude Code after installing so MCP servers spawn correctly. You can also browse and install everything through the /plugin UI once the marketplace is added.

Behind the marketplace

Hi, I'm Álvaro Lillo.

I build smart contracts on Sui and EVM — and the tooling that makes building them with Claude Code faster, safer, and better grounded. Contract Hero is where I ship that tooling as open-source Claude Code plugins.

Everything here is doc-first and battle-tested in real engagements: sui-pilot for Move work, code-forge for multi-agent builds, and the Agentic Community College for teaching it all.
