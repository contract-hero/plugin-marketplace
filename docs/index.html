Add once, install anything

claude-code
# register the marketplace
/plugin marketplace add contract-hero/plugin-marketplace

# install whatever you need
/plugin install sui-pilot@contract-hero
/plugin install code-forge@contract-hero
/plugin install agentic-community-college@contract-hero

Restart Claude Code after installing so MCP servers spawn correctly. You can also browse and install everything through the /plugin UI once the marketplace is added.

The catalog

Three of the ten. The rest live on the full catalog page.

sui-pilot

Turns Claude into a Sui/Move expert grounded in current docs — 812 bundled MystenLabs docs, a Move LSP bridge for live diagnostics, and a Sui Prover formal-verification wrapper.

suimovelspproverwalrus
/plugin install sui-pilot@contract-hero
Site ↗ GitHub ↗

agentic-community-college

The framework that turns a Claude Code session into a coding tutor. A lesson is split into chapters defined by tests; the conductor implements each chapter in a seeded workspace, explains it with an HTML artifact, and closes with an end-to-end test and a summary page.

First course on the v0.3 chapter model: acc-claude-sdk, building agents with the Claude Agent SDK. Previous work on the v0.2 model: acc-deepbook-course and acc-evm-wal.

frameworkchaptersmcpartifacts
/plugin install agentic-community-college@contract-hero
Site ↗GitHub ↗

code-forge

A multi-agent build system. One brief becomes a tested, reviewed proof-of-concept: a planner drafts the spec, best-of-N implementers race to pass tests, and dimensional reviewers audit every cycle — TDD kept honest by a hook.

multi-agenttddbest-of-norchestration

Beyond plugins

skypies

The same maker builds skypies: manage the files your agents produce, and organize all your pies-in-the-sky. The Mac app shares Claude Code HTML artifacts to your iPhone over an end-to-end encrypted peer-to-peer link — no server in the middle.

Behind the marketplace

Hi, I'm Álvaro Lillo.

I build smart contracts on Sui and EVM — and the tooling that makes building them with Claude Code faster, safer, and better grounded. Contract Hero is where I ship that tooling as open-source Claude Code plugins.

Everything here is doc-first and battle-tested in real engagements: sui-pilot for Move work, code-forge for multi-agent builds, and the Agentic Community College for teaching it all.
