◆ Sui Move

sui-pilot

Sui Move development plugin — 812 bundled docs, Move LSP integration, Sui Prover formal verification, and five specialized skills (code quality, security review, math safety, formal specs, verification).

suimovelspproverwalrusseal

sui-agent-tank

Guided evaluation harness — grade a Sui-stack context bundle (a skill folder or a Claude Code plugin) by GitHub URL. /tank clones it, auto-detects the kind, runs a containerized agent through compile/test gates plus Move anti-pattern traps and a cross-model judge, and reports.

suimoveevalgradingtank

◆ Agentic Community College

agentic-community-college

The framework that turns a Claude Code session into a coding tutor. A lesson is split into chapters defined by tests; the conductor implements each chapter in a seeded workspace, explains it with an HTML artifact, and closes with an end-to-end test and a summary page. Pair it with any acc-content plugin to teach a domain.

frameworkcoursemcplearning
/plugin install agentic-community-college@contract-hero
Site ↗GitHub ↗

acc-claude-sdk

Build agents with the Claude Agent SDK in TypeScript, chapter by chapter, with tests as the contract. Lesson 1 runs a query() and reads the result message, adds a custom in-process tool via createSdkMcpServer(), and wraps it in a testable CLI. First course on the ACC v0.3 chapter model. Requires the agentic-community-college plugin to run.

claudeagent-sdktypescriptacc-content
/plugin install acc-claude-sdk@contract-hero
GitHub ↗

acc-deepbook-course

Previous work, built on the ACC v0.2 section model: hands-on lessons that walk learners through building Sui DeepBook integrations end-to-end. Requires the agentic-community-college plugin to run.

suideepbookdefiacc-content

acc-evm-wal

Previous work, built on the ACC v0.2 section model: teaches the basics of Walrus decentralized storage and how to integrate it with Solidity smart contracts. Ships a short Foundry-based lesson, runnable offline, that builds a WalrusAnchor contract end-to-end. Requires the agentic-community-college plugin to run.
